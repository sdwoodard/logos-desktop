# Presentation assets

The social preview is an original LogosDesktop composition. Its Book Open Text
glyph is adapted from Lucide under ISC, with the same revision and attribution
as [the application icon](../../logos_desktop/img/ATTRIBUTION.md). Preserve the
[ISC license](../../logos_desktop/img/lucide-LICENSE.txt). Other authored layout
and artwork is under the project [MIT license](../../LICENSE).

Application screenshots must show an actual controller with demonstration data,
without accounts, tokens, private paths or library content. Capture provenance
and validation records remain with the maintainer. A preview image is not an
endorsement by the managed product's vendor.

`home-light.png` and `home-dark.png` show the actual 1.0.0 candidate's first-run
Home on KDE Wayland with an empty demonstration profile. They were captured from
the native application window, not drawn UI mockups. The light view uses the
application preference. The dark view follows the test desktop's system palette.
